# Website image sources

- `overview.png`, `small.png`, `medium.png`, `large.png`: captures of the maintainer's original Windows 1.1.0 build, running in an isolated demo profile. They contain synthetic usage and masked example accounts.
- `*-light.jpg` UI images: AI-generated light-palette concepts based on those captures. They are labeled as concepts on the website, not represented as a shipped 1.1.0 theme. Text and small details may differ from the application.
- `hero-studio.jpg`, `hero-studio-light.jpg`, `sizes-studio.jpg`, `sizes-studio-dark.jpg`: original glass-studio artwork generated with the built-in image tool, compressed for web delivery. No specific image-model version was exposed by that tool.
- `icons/*.svg`: provider logos from the MIT-licensed CodexBar resources. See `../licenses/CodexBar-MIT.txt` and `../NOTICE.txt`.

The website's light/dark/system and accent controls affect its presentation. They do not modify the downloadable Windows application.
