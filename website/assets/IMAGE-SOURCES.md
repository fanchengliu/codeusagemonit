# Website image sources

- `overview.png`, `small.png`, `medium.png`, `large.png`: 2× captures of the Windows 1.1.0 app running in its isolated `--demo` profile. They contain synthetic usage and masked example accounts. The sizes section no longer shows these files; it draws theme-following HTML mocks of the same four layouts.
- `og.png`: social preview (1200 × 630) rendered from HTML with the site's own styles and `overview.png`.
- `icons/*.svg`: provider logos from the MIT-licensed CodexBar resources, tinted with CSS masks. See `../licenses/CodexBar-MIT.txt` and `../NOTICE.txt`.

The interactive demos on the page (app replica, quota meters, usage dashboard, terminal) are built in HTML and show demo data consistent with the app's `--demo` mode. No AI-generated imagery is used.
