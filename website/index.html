安装和更新

通过 Releases 获取最新更新即可。

需要把所有账号重新登录一遍吗？

多数平台可以复用已有 CLI 或编辑器的登录状态。需要密钥的平台，可在卡片或设置里连接。

所有平台的数据都一样吗？

不同平台开放的接口和本机日志不同。

怎么安装？需要 Node.js 吗？

下载 Windows x64 压缩包，完整解压到可写目录，运行 codeusagemonit.exe。1.1.0 使用自己的原生统计引擎，不依赖 Node.js。

是否会窃取你的隐私上传？

使用本地现有的提供程序会话、OAuth、设备流、API 密钥和本地文件。不存储密码。Cursor 的 Cookie 请求头来自本机编辑器会话，不读取浏览器 Cookie。查询额度时，仅向对应平台或你配置的自定义接口发送必要的认证请求。
