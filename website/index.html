    03计价与速度
    
      
    算得准价格跟着官方走
    
      
    费用 = 本机日志里每次请求的 Token × 该模型的官方 API 单价。价目表每天与官方同步一次，断网时用内置价目；速度按每次请求端到端计时；走中转站的调用，也归到具体站点。
    
    
    
    
    
      
    
        
    361 款模型，与官方同步计价
    
        
    官方 API 单价，含长上下文阶梯、缓存读写和 Fast 模式倍率。
    
        
    已同步 · 价目日期 2026-09-30每 24 小时检查一次更新
    
        
    
          
        
    
        
    
        
    模型输入输出缓存读
    
        
    美元 / 百万 Token · 来源：厂商官方价目（经 LiteLLM、models.dev 汇总）
    
      
    
      
    
        
    真实输出速度
    
        
    输出 Token ÷ 请求全程耗时，首字延迟和中转延迟都算在内，每个工具分开算。
    
        
    
      
    
      
    
        
    中转站，也算得清
    
        
    配合 CC Switch 来回切换供应商，每次调用照样归到具体站点。

    06隐私
    
      
    数据留在你的电脑上
    
    
    
    
    
      
    只记数字
    只把 Token、请求数、耗时和模型名写进本地的小时索引，不保存对话内容。
    
      
    登录留在原处
    各工具的登录令牌留在它们自己的目录，只读取，不复制。
    
      
    密钥加密
    手动填写的 API Key 用 Windows DPAPI 加密，只有当前用户能解密。
    
      
    没有遥测
    没有自己的服务器。查额度只连对应的服务商；价目表每天从 GitHub 取一次，不带任何账户或用量信息，可在设置里关掉。
    
    
    
  
    

    



    
  
    
    
    
      
    07FAQ
    
      
    常见问题
    
    
    
    
    
      
    怎么安装？需要什么运行环境？
    三种方式任选：Scoop、PowerShell 一行脚本，或下载 zip 解压到一个可写的文件夹（例如 D:\Tools）直接运行 codeusagemonit.exe。不需要安装程序、Node.js 或管理员权限，Windows 10 / 11 自带的 .NET Framework 4.8 就够了。
    
      
    怎么升级和卸载？
    Scoop：scoop update codeusagemonit / scoop uninstall codeusagemonit，数据放在 Scoop 的 persist 目录，升级不丢。PowerShell 脚本：再运行一次就是升级；卸载时删除 %LOCALAPPDATA%\Programs\codeusagemonit 并从用户 PATH 里去掉它。zip 版：用新版本覆盖旧文件即可，data 文件夹保留。
    
      
    为什么提示“Windows 已保护你的电脑”？
    程序没有购买代码签名证书。点“更多信息 → 仍要运行”即可；也可以先用下方的 SHA-256 核对下载的文件。Scoop 和 PowerShell 脚本会自动核对 SHA-256。
    
      
    需要把账号重新登录一遍吗？
    不需要。Codex、Claude Code、Cursor、Antigravity、Grok 直接复用本机已有的登录；DeepSeek、Kimi、OpenCode、ZCode 填 API Key；Copilot 用 GitHub 设备码登录。
    
      
    显示的费用是真实账单吗？
    不是。费用 = 本机日志里的 Token × 官方 API 单价，是 API 等价参考；订阅套餐按月费计费，不会产生这笔账单。
    
      
    价目表怎么和官方同步？
    项目仓库里的 pricing.json 每天由 GitHub Actions 从 LiteLLM 与 models.dev 重新整理（二者收录各厂商官网公布的 API 单价）。软件每 24 小时检查一次，有新版本就下载并校验，然后按新价目重算；下载失败或在设置里关掉时，继续用内置价目。
    
      
    输出速度怎么算？
    输出 Token（含思考）÷ 从发出请求到最后一段输出的时间，包含首字延迟与网络、中转站延迟。只统计输出不少于 50 Token 的请求，每个工具单独计算。
    
      
    界面是什么语言？有 macOS 版吗？
    软件界面目前是简体中文，只支持 Windows。macOS 上可以试试 CodexBar，本项目的界面思路参考了它。
