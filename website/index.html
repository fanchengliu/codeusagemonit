      常见问题
      
      
      
        
      怎么安装？需要什么运行环境？
      可以下载安装程序（可选目录和开始菜单，可选桌面快捷方式、开机启动和 PATH，在“Windows 设置 → 应用”里卸载），也可以用 Scoop、PowerShell 一行脚本，或下载 zip 解压到可写文件夹后运行。默认不需要管理员权限。不需要 Node.js，系统自带的 .NET Framework 4.8 就够了。
      
        
      怎么升级和卸载？
      安装程序：再运行新的安装程序就是升级，设置保留在 %LOCALAPPDATA%\codeusagemonit；卸载在 Windows 设置 → 应用里，会询问是否删除设置。Scoop：scoop update codeusagemonit / scoop uninstall codeusagemonit，数据放在 Scoop 的 persist 目录，升级不丢。PowerShell 脚本：再运行一次就是升级；卸载时删除 %LOCALAPPDATA%\Programs\codeusagemonit 并从用户 PATH 里去掉它。
      
        
      为什么提示“Windows 已保护你的电脑”？
      程序没有购买代码签名证书。点“更多信息 → 仍要运行”即可。
      
        
      需要把账号重新登录一遍吗？
      不需要。Codex、Claude Code、Cursor、Antigravity、Grok 直接复用本机已有的登录；DeepSeek、Kimi、OpenCode、ZCode 填 API Key；Copilot 用 GitHub 设备码登录。
      
        
      价目表怎么和官方同步？
      项目仓库里的 pricing.json 每天由 GitHub Actions 从 LiteLLM 与 models.dev 重新整理（二者收录各厂商官网公布的 API 单价）。软件每 24 小时检查一次，有新版本就下载并校验，然后按新价目重算；下载失败或在设置里关掉时，继续用内置价目。
