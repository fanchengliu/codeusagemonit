BEFORE YOU START.

几个你可能关心的问题。

显示的费用，就是我实际支付的账单吗？＋

不是。费用是根据本机记录的 Token 和价格表计算的 API 等价估算，方便比较用量，不等于订阅账单，也不是剩余额度的美元价值。

需要把所有账号重新登录一遍吗？＋

多数平台可以复用已有 CLI 或编辑器的登录状态。需要密钥的平台，可在卡片或设置里连接。GitHub Copilot 支持设备码登录。

所有平台的数据都一样吗？＋

不同平台开放的接口和本机日志不同。DeepSeek 显示余额，Pi 只显示本机历史；未返回的额度或尚未记录的数据不会被补造。

怎么安装？需要 Node.js 吗？＋

下载 Windows x64 压缩包，完整解压到可写目录，运行 codeusagemonit.exe。1.1.0 使用自己的原生统计引擎，不依赖 Node.js 或 ccusage 程序。

它和 CodexBar 是什么关系？＋

codeusagemonit 是独立的 Windows 项目，交互思路参考 CodexBar，不是 CodexBar 官方 Windows 版本。项目和第三方素材的许可说明随包提供。
