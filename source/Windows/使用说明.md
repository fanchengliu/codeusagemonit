# codeusagemonit 0.7

Windows 版 AI 用量监控。参考并移植 CodexBar 的交互与部分额度解析逻辑，用一个托盘图标统一查看 11 个内置平台及自定义接口。

## 打开与使用

完整解压到可写目录后，双击 **codeusagemonit.exe**。已安装的用户也可以使用原来的桌面快捷方式。

- 左键单击托盘图标：展开 / 收起面板（面板在前台时再点一次即收起）。
- 右键托盘图标：打开当前尺寸、刷新、设置、显示尺寸（四选一）、重置窗口位置、退出。
- 面板顶部：刷新、图钉（完整布局保持展开 / 失焦收起）、独立设置窗口、收起。紧凑布局按 F5 刷新当前平台，Ctrl+F5 刷新全部；Esc 先返回概览，再收起。
- 标签栏只显示**已启用**的平台；有问题的平台标签右上角会出现琥珀色小点。
- **概览**：近 30 天 API 等价费用（按平台堆叠的每日柱状图）+ 每个平台一张卡片。点图表下方的平台标签（全部 / Codex / Claude …）只更新图表区域的金额、Token 和柱状图，下方额度条保持原位；点卡片标题行进入该平台详情。
- **单独刷新**：账户卡片和详情页的刷新按钮只查询该平台的额度；Pi 刷新自己的本机历史。完整面板卡片的更多操作菜单提供查看详情、复制用量和连接 / 更换账号。
- 启用的平台较多时，标签栏自动排成两行。
- 所有百分比表示**剩余**。接口没有返回的额度窗口不会显示。
- 进度条下方的节奏提示：绿色“余量”表示比线性节奏省，琥珀色“超前消耗”表示比线性节奏快，并给出预计用尽时间。
- 默认每 5 分钟刷新。查询失败时保留上次成功读数，并显示提示和更新时间。
- 四种布局都能拖动四边或四角调整宽高，并分别保存大小和位置。完整面板拖标题移动；小 / 中 / 大可拖动空白区域移动。
- **Ctrl＋滚轮**调整界面缩放，也可以在设置中使用缩放滑块。

关闭面板不等于退出软件。完全退出请使用托盘右键菜单。

## 设置

点击齿轮打开独立设置窗口，主面板保持原来的布局和大小并继续更新。重复点击只激活已有设置窗口。点“保存”才应用修改；“取消”、关闭窗口或 Esc 放弃修改及透明度预览。

- **显示的平台**：点选平台胶囊开关。关闭的平台不联网查询，也不出现在标签栏。“统计第三方 API 用量”开关控制「第三方」页。
- **窗口**：显示布局（小 / 中 / 大 / 完整，四选一）、置顶（默认关闭）、完整面板失焦自动收起、毛玻璃透明度、界面缩放、重置当前布局的位置与尺寸。材质仅保留毛玻璃。
- **背景透明度**：0–100，0 为不透明，100 移除深色覆盖层、保留 Windows 原生材质。实时预览；取消或返回会恢复已保存值。旧版“不透明”设置自动迁移为毛玻璃、透明度 0。系统不支持原生材质时回退为实色。
- **数据与网络**：自动刷新间隔（1–60 分钟）、网络代理（自动 / 直连 / 自定义）、隐藏邮箱、开机自启。
- **账号与密钥**：GitHub Copilot 登录；DeepSeek、Kimi Code、OpenCode Go、ZCode 的 API Key（Kimi / ZCode 可选国内或国际）。密钥以 Windows DPAPI 加密保存在本机，同名环境变量优先。
- **自定义平台**：添加、测试、编辑、删除自己的平台（见下文）。
- 设置页打开期间不会因失焦自动收起，方便去别的窗口复制 API Key。

## 在卡片中连接平台

未连接或登录过期时，概览卡片和平台详情中直接显示连接入口；接口出错时点“重新连接…”。不需要先去设置页：

- DeepSeek / Kimi / OpenCode / ZCode：粘贴 API Key，点“保存并连接”；Kimi、ZCode 可选择区域。未提交的输入在刷新时保留。
- Copilot：点“使用 GitHub 登录”，复制设备码到 GitHub 授权，成功后自动刷新。
- Codex / Claude / Grok：打开已安装 CLI 的登录终端；Claude 打开后输入 `/login`。完成后点“我已登录，刷新”。
- Cursor / Antigravity：打开对应应用并登录，然后点“我已登录，刷新”；Antigravity 需保持应用运行。未检测到安装位置时会提示手动打开。
- 小 / 中 / 大布局中点击“连接”或“账号”按钮，在当前窗口内打开连接页，宽高保持不变；内容较长时可以滚动。返回按钮回到当前平台。
- 自定义平台可以在当前连接页填写密钥；“编辑接口定义”会打开独立设置窗口中的编辑器。

设置页仍保留原有账号管理入口。

| 平台 | 连接方式 | 展示内容 |
| --- | --- | --- |
| Codex | 在 Codex 应用或 CLI 中登录 | 账户实际返回的周期额度、重置时间、限额重置额度 |
| Claude | 在 Claude Code 中登录 | 5 小时、每周及返回的模型额度 |
| Cursor | 在 Cursor 编辑器中登录 | 套餐总量、Auto、API 用量 |
| Antigravity | 优先读取正在运行且已登录的桌面应用，登录凭据作为回退 | 周期 / 模型额度 |
| DeepSeek | 在卡片或设置中填写 API Key | API 账户余额，按币种分别显示 |
| Grok | 在 Grok Build CLI 中运行 `grok login` | 当前账期的订阅额度 |
| GitHub Copilot | 设置 → 账号与密钥 → **使用 GitHub 登录**（OAuth 设备码，只申请 `read:user`）；也会复用 copilot.vim / JetBrains 等官方客户端已保存的授权 | 每月高级请求、对话额度 |
| Kimi Code | 设置中填写 Kimi Code API Key（kimi.com/code/console），或环境变量 `KIMI_CODE_API_KEY`；可选国内 / 国际 | 5 小时、每周、每月总量 |
| OpenCode | OpenCode Go 订阅的 API Key，或环境变量 `OPENCODE_API_KEY` | 5 小时、每周、每月 |
| ZCode | 智谱 / Z.ai 的 API Key（GLM 编码套餐），或环境变量 `Z_AI_API_KEY`（国内还认 `BIGMODEL_API_KEY` 等）；可选国内 open.bigmodel.cn / 国际 api.z.ai | 5 小时、每周、MCP 工具调用 |
| Pi | 无需登录 | 只有本机日志用量（Pi 没有账户额度） |

后五个平台默认不启用，在 设置 → 显示的平台 里点亮即可。所有平台的本机 Token / 费用历史都来自 ccusage（Copilot、Kimi、OpenCode、ZCode、Pi 都已支持）。

不使用浏览器 Cookie：Windows 上的 Chrome 对 Cookie 做了应用绑定加密，普通程序无法读取，读取其他应用的会话也不利于隐私。

登录令牌过期时，面板会提示具体做法：Codex / Claude Code 只需在原应用里运行一次即可自动续期，然后点刷新。

## 本机用量怎么看

平台详情页的“本机用量”卡片：

| 行 \ 列 | 今日 | 本周额度（当前窗口） | 近 30 天 |
| --- | --- | --- | --- |
| 费用 | API 等价费用 | ≈ 当前额度窗口内的费用 | 30 天合计 |
| Token | 新增输入 + 输出 + 缓存命中 + 缓存写入 | 窗口内 Token | 30 天合计 |

- **Token 构成**：新增输入、输出、缓存命中（Claude 另有缓存写入）和缓存命中率，口径与 CC Switch 的“使用统计”一致，可以直接对照。
- **额度窗口用量**：窗口起点由服务商返回的重置时间和周期长度反推。
  - **Codex**：逐条读取 `~/.codex/sessions` 和 `archived_sessions` 的会话日志，按小时精确累计 Token（标“按小时精确 Token”）。费用按每天的 API 等价单价折算，所以标 **≈**。
  - 其他平台：本地历史只有按日汇总，跨越窗口起点的那一天不计入，显示为保守下界 **≥**。
- 每日柱状图悬停可看当天费用和 Token。

## 四种显示尺寸

设置 → 窗口 → **显示尺寸**，或托盘右键 → 显示尺寸，选择 **小 / 中 / 大 / 完整**。始终只有一个监控主窗口，设置另开窗口。四种布局的背景区域均可右键选择尺寸，完整面板也支持。

| 尺寸 | 内容 |
| --- | --- |
| 小 | 紧凑概览，或一个主要额度窗口；详情、复制和连接均可就地操作 |
| 中 | 概览，或两个主要额度窗口、费用与图表；可就地展开更多明细 |
| 大 | 概览，或三个主要额度窗口、节奏和用量；详情中可看全部额度与每日记录 |
| 完整 | 完整概览、平台详情、账号连接及设置页面；可自由调整宽高 |

- **切换平台**：点击标题旁的下拉菜单，或点击概览中的平台卡片；返回箭头回到概览。滚轮用于滚动内容。
- **明细与历史**：点击额度条区域或“用量详情”，可查看全部额度、每日记录和最常用模型；7／30 天按钮切换历史范围。
- **复制用量**：生成当前平台的文字摘要，显示复制成功提示；摘要不包含密钥或邮箱。
- **右键菜单**：四种尺寸、刷新全部、总在最前、设置、收起到托盘。
- 只有余额的平台（DeepSeek、自定义平台）显示余额；Pi 这类没有额度的平台显示本机用量。“支出”只在有本机日志时出现。
- 四种布局均为正常可交互窗口，默认不置顶；点击可激活。设置单独弹出，连接页留在当前大小。
- 100% 缩放时默认小为 260×320、中为 420×320、大为 420×540、完整为 420×790 逻辑像素。每种布局都可自由拖边调整，右键“恢复当前布局默认尺寸”可恢复。

这是普通 Windows 桌面程序，不接入 Windows 11 的系统小组件面板。

## 命令行（codeusage）

程序目录里的 `codeusage.exe` 是命令行版，和桌面版共用 `data` 目录（设置、密钥、缓存都是同一份）。把程序目录加入 PATH 后可以在任意终端使用：

```powershell
codeusage                       # 各平台额度与本机用量（读取桌面版缓存，不联网）
codeusage usage -p codex        # 实时查询 Codex 额度
codeusage cost --days 30        # 近 30 天每天的费用和 Token
codeusage thirdparty            # 第三方 API 用量
codeusage providers             # 平台列表、启用状态、凭据来源
codeusage status --json         # JSON 输出，便于脚本 / 状态栏调用
```

选项：`-p, --provider <id>`（可逗号分隔）、`--all`（包括未启用平台）、`--days <n>`、`--refresh`（cost 先重新扫描本机日志）、`--json`、`--no-color`（也认 `NO_COLOR` 环境变量）。额度进度条在终端里同样是 24 格分段样式。退出码：0 正常，1 实时查询全部失败，2 参数错误。

## 自定义平台

没有内置支持的服务（中转站后台、自建网关、公司内部额度接口……），只要有一个返回 JSON 的 GET 接口，就能接进来：设置 → 自定义平台 → **添加自定义平台**，写一段 JSON 定义，点“测试”确认字段取对了，再“保存”。保存后它和内置平台一样有标签页、卡片和进度条。

```json
{
  "name": "我的中转站",
  "url": "https://api.example.com/api/usage",
  "auth": "bearer",
  "windows": [
    { "label": "每日", "used": "data.daily.used", "limit": "data.daily.limit", "resetsAt": "data.daily.reset_at", "windowHours": 24 },
    { "label": "每月", "remainingPercent": "data.monthly.left", "ratio": true }
  ],
  "balance": { "amount": "data.balance", "currency": "USD" },
  "plan": "data.plan_name",
  "account": "data.email"
}
```

| 字段 | 说明 |
| --- | --- |
| `name` | 显示名称（1–40 字） |
| `id` | 可选，小写字母 / 数字 / 连字符；省略时由名称生成 |
| `color` | 可选，`#RRGGBB` |
| `url` | 接口地址。必须是 https；只有本机或局域网地址（127.x、192.168.x、10.x、172.16–31.x、.local）可以用 http |
| `auth` | `none`、`bearer`（Authorization: Bearer）、`token`（Authorization: token）、`x-api-key`，或 `header` 加 `"header": "X-Custom-Key"` |
| `windows[]` | 最多 6 个额度窗口。`label` 必填，另外**只选一种**：`usedPercent`（已用 %）、`remainingPercent`（剩余 %）、`used` + `limit`、`remaining` + `limit`。值是 0–1 比例时加 `"ratio": true` |
| 窗口可选项 | `resetsAt`（ISO 时间或 Unix 秒 / 毫秒）、`resetInSeconds`（距重置秒数）、`windowHours`（周期长度，用于节奏估算） |
| `balance` | `amount` 路径 + `currency`（三位代码）或 `currencyPath` |
| `plan`、`account` | 套餐名、账户名的路径 |

路径写法：`data.items[0].used`，只支持点号和数组下标，不支持表达式或脚本。

安全规则（参照 CodexBar 的自定义平台设计）：
- 只发 GET 请求；**不跟随重定向**（防止密钥被转发到别的地址）；响应超过 1 MB 或 15 秒未完成即中止。
- 密钥不写在 JSON 里：在编辑页单独填写，按 `auth` 方式只放进请求头，用 DPAPI 加密保存为 `data/custom-<id>.key`。
- 路径里找不到的字段不会被当成 0，而是不显示；一个字段都取不到时报错。
- 定义保存在 `data/custom-providers.json`，只来自你自己的输入，没有在线下载或导入。

## 第三方 API（中转站）用量

当 Claude Code 或 Codex 接的是第三方接口（中转站、公益站、自建网关等）时，官方订阅的额度条不会变化，这部分用量显示在 **「第三方」** 页。只要近 30 天有第三方用量或当前正在使用第三方接口，这个标签就会出现（设置里可以关闭）。

**只统计用了多少，不显示剩余额度。** 各服务商的周、月限额由其自行设定，也不对外公开，本机无法得知，所以这里没有额度进度条。

每个接口一张卡片：今日 / 近 7 天 / 近 30 天的 Token、请求次数、每日柱状图、主要模型，以及“官方价参考”（按官方 API 单价估算，中转站实际按自己的倍率或套餐扣费，以其后台为准）。

用量怎么归到具体接口：

| 客户端 | 判断依据 |
| --- | --- |
| Codex | 会话日志记录了 `model_provider`，能**精确**区分官方和第三方；是哪一家，看切换时间线 |
| Claude Code | 日志不记录接口地址。本软件监视 `~/.claude/settings.json` 的 `ANTHROPIC_BASE_URL`，记下每次切换的时间，再按时间归属 |
| 两者 | 缺少官方 request-id 的 Claude 记录（官方接口一定会返回它）归为 **“疑似中转站”** |

局限：
- 本软件开始记录之前、且带官方 request-id 的 Claude 用量，无法判断是官方还是透传型中转，会单独说明、不计入任何接口。
- 用 CC Switch 切换供应商后，**已经在运行的**客户端会话可能仍连着旧接口，而用量会按新接口统计。切换后重启客户端最准确。
- 同一站点的多个账号，靠 API Key 的 6 位 SHA-256 指纹区分（只保存指纹，不保存密钥本身）。
- 如果安装了 CC Switch，会只读地读取它的供应商名称，用来把 `anyrouter.top` 这类地址显示成你起的名字；不读取其中的密钥。

## 为什么和 CC Switch 的数字不一样？应该信哪个？

2026-09-29 用同一份本机日志逐项核对过：

| 项目 | 本软件（ccusage） | CC Switch | 结论 |
| --- | --- | --- | --- |
| Codex 今日 Token | 1,795,411 新增输入 + 556,773 输出 + 143,120,640 缓存命中 = 145,472,824 | 完全相同 | **Token 两边一致，都可信** |
| Codex 今日费用 | $294.52 | $188.91 | 差在计价规则 |
| gpt-6-astra 单价 | $10 / $1 / $50（输入 / 缓存 / 输出，每百万）；**单次请求输入 > 272K 时整次请求输入与缓存 ×2、输出 ×1.5** | 统一 $10 / $1 / $50，**不计长上下文分档** | 本软件符合 OpenAI 官方价目 |
| claude-opus-5-5、gpt-6-sol、gpt-6-luna | 有价格 | 价格表未收录，按 $0 计 | CC Switch 偏低 |
| 已被删除的会话文件 | ccusage 重新扫描时统计不到 | CC Switch 已同步进自己的数据库，仍保留 | CC Switch 偏全 |

当天 588 次请求里有 222 次输入超过 272K（最大约 579K），按官方分档重新计算正好得到 $294.52；没有超长请求的日子（如 9-24、9-28）两边金额完全相同。

**结论**：Token 数两边都可信；**费用以本软件为准**（包含长上下文加价与新模型价格）。为了弥补“会话文件被删后历史缩水”的问题，本软件现在对过去的日期保留曾经观测到的最大值，Codex 的小时索引也会保留已删除文件的计数。

注意：这些费用都是 **API 等价参考**。Pro 等订阅套餐实际按月费计费，并不会产生这笔账单。

## 代理

设置中的代理默认是“自动”：优先使用 Windows 系统 HTTP 代理，再读取 HTTPS_PROXY / HTTP_PROXY 环境变量。需要时选“自定义”并填写 `http://127.0.0.1:端口`。

代理仅应用于本程序，不修改系统或其他 CLI 的全局环境变量。

## 费用与隐私

- 费用由 ccusage 根据**本地日志和离线价格表**计算，是 API 等价估算，不等于订阅账单或剩余额度的美元价值。
- 没有保存在这台电脑上的历史不会出现在图表中。日期按 Windows 当前时区划分。
- 原有账户凭据保留在各自应用中。本程序不复制登录 token 到自己的配置或日志。
- DeepSeek API Key 由 Windows DPAPI 加密，只能由当前 Windows 用户解密。
- 本程序的设置和缓存都位于本目录的 `data` 文件夹：`settings.json`（设置）、`quota-cache.json`（上次额度，含账户邮箱）、`history.json`（每日用量）、`codex-logs.json` / `claude-logs.json`（按小时、按模型的 Token 计数，不含任何会话内容）、`endpoints.json`（接口切换时间线：地址、名称、密钥指纹）、`custom-providers.json`（自定义平台定义，不含密钥）、`*.key`（DPAPI 加密的密钥，换电脑或换 Windows 用户后无法解密）。请勿直接公开分享。
