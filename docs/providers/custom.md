# 自定义接口

[← 返回项目](../../README.md) · [下载](https://github.com/fanchengliu/codeusagemonit/releases)

> 适用于 codeusagemonit 1.1.0。连接方式：**API Key · 自定义**。

## 数据来源

连接你自行配置的 HTTP JSON 接口。支持 none、bearer、token、x-api-key 与自定义请求头鉴权；不执行脚本，不下载远程平台定义。

## 连接步骤

1. 打开「设置 → 自定义平台 → 添加」，填写名称、接口 URL 和字段映射。
2. 密钥填在独立的密钥输入框，不要写进 JSON 定义或 URL。
3. 点击测试，确认映射结果后保存；卡片中可点击「编辑接口与密钥」继续修改。

## 可以查看什么

- 最多 6 个额度窗口：已用百分比、剩余百分比，或用量与上限。
- 余额、币种、套餐和账号；可映射重置时间及周期长度。

## 限制

只支持 GET JSON 接口与点号 / 数组下标路径，不支持 JavaScript 或完整 JSONPath。公网地址要求 HTTPS；HTTP 只允许本机或私网。不支持用自定义 Cookie 请求头导入网页会话。自定义接口额度不同于「第三方」本机日志归类。

费用为本机记录的 API 等价估算，不是订阅账单。数据范围受服务端返回字段、本机日志与所选时间段限制。

## 隐私

手动填写的密钥或设备流令牌使用 Windows DPAPI 加密保存在本机 data 目录；只供当前 Windows 用户解密。 不存储密码。网络查询会把相应的鉴权信息发送到该提供商（自定义平台则发送到你配置的地址）。本机统计索引保存数值，不保存对话正文。

## 常见问题

确认字段路径真实存在，且百分比口径正确；0–1 比例需 ratio:true。缺失字段不会当作零。接口必须在 15 秒内返回，响应不得超过 1 MB，且不能依赖 HTTP 重定向。

查询失败时，界面可能保留上次成功读数；请结合更新时间与错误提示判断。
